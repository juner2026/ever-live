## 一、这是什么

给「潮汐回响」App 做的一个**星露谷式独立小游戏**，先做成单文件 HTML 独立跑，跑通后要挂进 App（作为独立板块，**不覆盖现有家园**）。

核心设想：**你在聊天框里说话，抬头看见 TA 在院子里浇水。**
TA 是和用户同居的 AI 伴侣，能自己走动、自己决定做什么，也能被指令控制。

## 五、已实现的功能（按模块）

### 1. 世界地图（小镇层）
- M8 系四张季节图，1536×1152，**1:1 显示不缩放**
- 9 个入口：农场·菜园 / 商店街 / 镇中心 / 山·矿洞 / 铁路 / 森林·法师塔 / 牧场 / 沙滩 / 沙漠
- 入口触发半径 **78px**
- A* 寻路 + 分轴滑墙，碰撞盒 **8×6**（必须小于一格 16px）
- 16 栋建筑整块挡死，水面挡，**樱花树可穿行**

### 2. 农场场景
- 1536×1024，一格 **32px**，网格 48×32
- **98 格菜地**（14 列 × 7 行），首行矮一点 40px、其余 47px
- 锄地（−3 体力）/ 浇水（−2 体力 +1 水）/ 播种 / 收获（+120 金）
- 井：**矩形距离 86px** 内出「打水」，水壶补满 20
- 水壶容量条：靠近井或菜地才显示
- 走出底部石子路（y > 860）出「离开 农场」

### 3. 时间 / 季节 / 天气
| 项 | 值 |
|---|---|
| 流速 | 10 游戏分钟 = 7 秒 |
| 一天 | 6:00 → 26:00（次日 2:00），**14 分钟** |
| 一季 | 28 天（约 6.5 小时） |
| 换季 | 自动切世界图和农场图 |
| 夜间 | 实时打光（19:00 渐暗、21:00 全黑），窗户/路灯/炉火自动亮 |
| 随身提灯 | 夜里玩家自带光圈，只照亮地面 |
| 天气 | 每晚随机：冬 55% 雪，其他 30% 雨 |

### 4. 扩建
- 顶部农地条 `◀ 1/1 ▶ ＋150`
- **无限扩建**，价格 = **150 × 已有农地数**
- 每块地的 98 格数据独立
- 过夜时**所有农地**的作物一起生长

### 5. TA（AI 伴侣）
- 12 帧走路，会自己溜达（17 个地点随机去，到了发呆 2~6 秒）
- 空闲时一直转向玩家
- 和玩家按 y 排序遮挡
- **对外接口 `window.TA_API`**：
  ```js
  TA_API.goToPlace('fountain')   // 17 个地点名
  TA_API.goTo(x, y)              // 世界坐标
  TA_API.say('文字')              // 头顶气泡 4.5 秒
  TA_API.stop()                  // 停下
  TA_API.auto(true/false)        // 交还/收回自主权
  TA_API.wherever()              // 走到玩家身边
  TA_API.state()                 // 读状态
  TA_API.places()                // 列出地点
  ```

### 6. 聊天窗
- AI 生成的像素面板（小/中/大三档背景图）
- **可拖动**（抓标题栏 ⠿），位置记在 `localStorage['te_chat_pos']`
- 可关闭，右下角「💬 聊天」重新打开
- 关键词命令：去XX / 过来 / 停 / 在哪 / 自己逛逛
- 位置切换后自动拉回屏幕内

### 7. 自动存档
- `localStorage['te_star_save_v1']`
- 每 5 秒 + 过夜 + 扩建 + 关页面时保存
- 存：时间/季节/金币/种子/体力/水/所有农地/场景/坐标
- 右上角闪「已存档 ✓」

## 六、踩过的坑（**别重犯**）

这一节比上面都重要，全是真金白银撞出来的。

### 1. 像素图不要缩放
- 3072 的图挤在 1024 屏幕里（0.5 倍缩小）**必糊**
- 现在的做法：**1:1 显示，绝不缩放**，`imageSmoothingEnabled = false`
- 世界 1536×1152 + 屏幕 1024 → 只能看到 2/3，这是取舍

### 2. 碰撞盒必须小于一格
- 旧版 `game.html` 用 20px 碰撞盒 + 16px 格子 → **测试 7 个目标 6 个走不到**
- 现在用 **8×6**，实测 9/9 可达

### 3. AI 画不出真像素画
- 试过：提示词要求 4×4 逻辑格 / 降采样量化 / 固定色板硬映射 —— **全部失败**
- 结论：`gpt-image-2` 只会画「像素风插画」，每格内部有渐变
- 想要硬像素只能靠素材包拼或手工画

### 4. 距离要用「矩形边缘」不是「中心」
- 井本身是 216×300 的碰撞体，人只能站外面
- 用「到中心距离」永远差 2px 够不着 → 改用**到矩形边缘的距离**

### 5. z-index / 位置重叠
- 「打水」按钮曾被底部工具栏整个盖住（z5 vs z9），看起来像没反应
- 现在布局从下往上：工具栏 16 / 水壶条 74 / 交互按钮 126

### 6. 顶栏三行，别挤一起
```
第 1 行 6px    左：HUD（时间+体力+金+种）  右：季节按钮
第 2 行 40px   中：农地条
第 3 行 86px   左：调试面板               右：已存档
```

### 7. 用 body class 控制显隐，别用 inline style
- 季节按钮有内联样式，`el.style.display='none'` 会被覆盖
- 现在用 `body.in-farm #seasons{display:none}`

### 8. 字符串替换要认准位置
- 有次把拖动逻辑插进了 `onclick` 回调里，导致「只有点了尺寸按钮才能拖」
- 改单文件 HTML 时，替换后一定 `node --check` 抽出的 script

### 9. 读档后别被默认值覆盖
- `init()` 里有一行无条件 `mapImg = seasonImgs[GAME.season]`，把读档进的农场图顶掉了
- 现在所有 `mapImg` 赋值都加了 `if(scene === 'world')` 守卫

## 七、美术素材说明

### 生成参数（gpt-image-2）
- 端点：`https://api.jumengai.net/v1/images/generations`
- 尺寸：世界图 `1536x1152`，角色 `1024x1024`（切 4 帧）
- 统一后缀：
  > TRUE 16-bit pixel art, flat solid colors, hard 1px outlines,
  > NO gradients, NO anti-aliasing, NO cast shadows on the ground

### 关键提示词技巧
- **季节变体**：用 `edits` 端点，把原图当输入，明确写「KEEP THE LAYOUT EXACTLY IDENTICAL，ONLY change the season」→ 布局 90% 保持一致，碰撞网格可以直接复用
- **角色**：洋红底 `#FF00FF`，事后用 Python 抠掉，切 4 帧缩到 96×96
- **UI**：洋红底 + 「THREE separate elements far apart」→ 按连通域切开

### 素材冗余
`生图/` 里有一堆作废的中间产物（M1~M7、A1、R1、S5 静态夜图等），**不要删**，留着对比；真正在用的是：
- 世界：`S1`（春）、`M8`（夏）、`S3`（秋）、`S4`（冬）
- 农场：`F1`（春）、`F2`（夏）、`F3`（秋）、`F4`（冬）
- 角色：`walk/`、`walk_ta/`
- UI：`W-面板-小/中/大`、`W-气泡capL/M/R`、`U-bar/sq/pill`

## 十、给下一个窗口的建议

1. **先跑起来再说**：`python3 -m http.server 8777` 打开看一遍，比读文档快
2. **改单文件 HTML 必须抽 script 做 `node --check`**，1399 行里任何一处括号错都会整页白屏
3. **素材在 `生图/` 里别乱删**，有些名字带「_」的是中间稿
