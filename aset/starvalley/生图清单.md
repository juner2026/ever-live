## 1. 一条硬结论：一张图装不下整个谷地

按 32px 一格算：

| | 尺寸 | 格数 |
|---|---|---|
| 世界 | 4096 × 3072 | 128 × 96 |
| 一张生成图 | 1536 × 1024 | **48 × 32** |
| 所以需要 | **4 × 3 = 12 张** | |

**这不是偷懒的问题，是物理约束**：要在 1536×1024 里塞进整个谷地，建筑只能画成 60px 宽——那就不是像素风，是缩略图。

所以分工是：

```
M1 全局总图  = 构图母版（定每个区在哪儿、什么颜色、什么关系）
R1–R12      = 真正的游戏美术（每块 1536×1024 = 48×32 格，真像素风）
```

**每张 R 图生的时候，都把 M1 里对应的那一块裁下来当参考图喂进去**，风格和接缝就能对上。

## 2. 真像素风的提示词公式

R1 验证有效，所有 R 图都套这个模板：

```
TRUE 16-bit pixel art game asset, NOT a painted illustration, NOT smooth.
The whole image is drawn on a coarse square pixel grid of about 192×128
logical pixels, so every pixel is a visible hard-edged square block.
Strict top-down orthographic view.

[主体内容]

STYLE RULES: flat solid colors only, NO gradients, NO shading ramps,
NO anti-aliasing, NO blur, NO texture noise. Every object outlined with
a hard 1-pixel dark border. NO cast shadows on the ground.
Limited palette of 32 colors: #F7B6C8 #FFD9E3 #D98098 #FFF6EE
#B98A62 #6B4A35 #8FCB7A #6FAF5E #8FD3E8.
No text, no labels, no UI, no borders.
```

**三条最容易漏的**：
1. `coarse square pixel grid of 192×128` —— 这句是像素感的来源，不写就会变插画
2. `NO gradients / NO anti-aliasing` —— 抗锯齿是像素风的头号敌人
3. `NO cast shadows on the ground` —— 长投影会把碰撞蒙版吃掉

## 7. 每张图的审核要点

1. **像素感**：能不能看出方块？有没有糊边？
2. **颜色**：粉色是不是晒过太阳的柔？
3. **地面**：有没有长投影？
4. **边缘**：主体有没有贴边（贴边就没法拼）
5. **酒馆/家**：这两个最重要的建筑，有没有辨识度
